저장 & 반영 방법

Publish 버튼

관리자 페이지에서 내용을 수정한 후 반드시 Publish 버튼을 눌러야 사이트에 반영됩니다. Publish 없이 뒤로 가면 변경사항이 저장되지 않습니다.

1
관리자 페이지에서 원하는 메뉴 클릭
2
내용 수정 (사진 교체, 텍스트 변경 등)
3
상단 Publish 버튼 클릭
4
약 1~2분 대기 후 실제 사이트에서 확인
⚠️ 주의 — 뒤로 가기 전 반드시 Publish
수정 후 Publish 없이 다른 메뉴로 이동하거나 뒤로 가면 "페이지를 떠나시겠습니까?" 팝업이 뜹니다. 이 경우 변경사항은 저장되지 않습니다.
크레딧 안내
Publish를 누를 때마다 Netlify 빌드 크레딧이 1개 사용됩니다. 기본 플랜은 월 300개, 유료 플랜은 월 1000개가 주어집니다. 개별 항목 메뉴(크루, 트레이너, 배너, 후기, FAQ)는 항목마다 Publish를 따로 눌러야 합니다. 단일 파일 메뉴(사이트 설정, 이미지 관리, 멤버십 등)는 여러 항목을 수정해도 Publish 1번으로 완료됩니다.
⚙️

클래스 시간표

단일 파일
반영되는 위치

Classes 페이지 — GymMaster 시간표 iframe

시간표는 GymMaster에서 자동 반영
클래스 시간표는 GymMaster 시스템과 직접 연결되어 있어 GymMaster에서 수정하면 사이트에 자동으로 반영됩니다. 이 메뉴는 embed 코드 자체가 변경될 때만 수정합니다.
⚠️ embed 코드 변경 시
GymMaster에서 제공하는 새 iframe 코드를 Embed HTML 코드 항목에 붙여넣고 Publish합니다. 잘못된 코드를 넣으면 시간표가 표시되지 않으니 주의하세요.

주의사항

🔴 개발자에게 문의해야 하는 작업
아래 항목은 관리자 페이지에서 수정 불가능합니다. 개발자에게 직접 요청하세요.

• 시설 Zone 이름 또는 설명 텍스트 변경
• 네비게이션 메뉴 항목 변경
• 페이지 레이아웃 구조 변경
• 새 페이지 추가
• 멤버십 종류 추가 또는 삭제
⚠️ 이미지 업로드 주의사항
• 파일 용량이 크면 페이지 로딩이 느려집니다. 업로드 전 반드시 압축하세요
• 권장 도구: tinypng.com (PNG/JPG) / squoosh.app (WebP 변환 가능)
• 세로형 슬롯(크루/트레이너)에 가로형 사진을 넣으면 잘려 보입니다
✅ 문제 발생 시
수정 후 사이트에 반영이 안 될 때: 브라우저 강제 새로고침 (Ctrl+Shift+R / Cmd+Shift+R) 후 1~2분 더 대기
그래도 안 될 때: 개발자에게 문의하세요
